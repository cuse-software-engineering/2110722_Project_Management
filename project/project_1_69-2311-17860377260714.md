## Project semester 1/2569 (20%)

### Objective

The objective of this project is to learn and practice software project management by applying PMBOK concepts together with Generative AI. Each group will propose a software development project and use GenAI to assist in creating project management artifacts, evaluating alternatives, and supporting project decisions.

### Team

1. Form a total of around 9 groups (3-5 students each). Use the same group as Requirements Engineering course.
2. Propose a software development project that you will manage. Use the project in the Requirement Engineering course.
3. Apply project management knowledge to deliver project management artifacts in your project report, submitted as three milestones.
4. Each member must actively participate in every milestone by creating prompts, analyzing GenAI outputs, revising artifacts, and contributing to shared project decision making.

### GenAI Usage

Students may use any GenAI tool or model. The project will not be graded based on which GenAI tool is used or the quality of the initial GenAI output. Instead, grading emphasizes the process of using GenAI with human-in-the-loop which includes prompt design, evaluation, revision, and decision making. Students should assume GenAI is an assistant rather than a project manager.

### Tasks

1. For each milestone, each member of the group will write prompts, evaluate the generated output, and revise prompts or perform manual edits.
2. See the descriptions and examples of the project artifacts in the lecture slides.
3. To reduce miscommunication among members, the group should establish shared understanding of the project context and project information. This creates a single source of truth to reduce inconsistency among generated outputs from different members.
4. For each milestone, each group member must contribute at least two prompts. The group should plan and distribute prompt engineering tasks to each member appropriately. That is, a simple artifact may require a single prompt, while a complex artifact may result from multiple prompts.
5. The recommended prompt frameworks are listed below. Clearly specify each part of the prompt text with the corresponding framework component, such as "[character] You are a senior project manager in a software company…"
   1. **RTF** for a quick request: Role (who the GenAI acts as, like a risk manager), Task (what specific work to do), and Format (how to display the result, like a table or bullet list). See PMI video <https://youtu.be/kFajLF7W160?si=KTTpOK_0DTvm-Dcb>
   2. **CREATE** for a more complex task: Character (persona, background, or professional mindset the GenAI must assume), Request (task or objective you need completed), Examples (samples to show the GenAI exactly what "good" looks like), Adjustments (specific project information, constraints, rules, or guidelines), Type of Output (structure of the final delivery, such as an executive summary or a markdown table), and Evaluation (evaluation criteria to fine-tune the results). See PMI video <https://youtu.be/CuynTRSveLg?si=NH-x6zDzgLlK3TKK>
6. Students should consider the following GenAI output evaluation criteria:
   1. **Requirement Satisfaction:** Does the output satisfy the requirement and information stated in the prompt? Is anything missing or incorrect?
   2. **PMBOK Correctness:** Is the output consistent with PMBOK concepts or terminology taught in class?
   3. **Project Consistency:** Is the output consistent with the project scope, assumptions, and previously developed artifacts?
7. Before milestone submission, all group members must form a Review Board to make a joint decision on final artifacts to be delivered for the milestone.
8. The final deliverables should be correct and complete but CONCISE. That is, you do not have to submit everything in the generated outputs. You may select necessary parts or summarize them where appropriate.

#### GenAI Log file

GenAI log file consists of all group members' prompt logs. Each member submits ONLY TWO prompt log records. Start each prompt log record on a new page. Each prompt log record has the following content.

| # | Item | Content |
|---|---|---|
| 1 | Artifact | What you want AI to do or create |
| 2 | Member | Member contributing to prompt design |
| 3 | AI Tool | Tool/model used |
| 4 | Initial Prompt | Initial prompt used |
| 5 | Initial Output | Output of initial prompt or brief summary |
| 6 | Review | Review result of the initial output against evaluation criteria, and if not yet satisfied, identify weaknesses |
| 7 | Revision | How the initial prompt is revised or how the initial output is manually edited |
| 8 | Final Output | Final output and why it is acceptable |

Note: You may perform review and revision several times. If so, just briefly summarize the results altogether and submit only one Final Output.
